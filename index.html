TabTo 서비스 매뉴얼

노드를 연결해 이미지·영상·음악·3D 결과물을 생성하는 비주얼 AI 워크스페이스, TabTo의 사용 안내서입니다. 왼쪽 목차에서 원하는 항목으로 이동하세요.

시작하기

01 시작하기/TabTo란?

TabTo란?

1.1 · 비주얼 AI 워크스페이스

TabTo는 비주얼 AI 워크스페이스입니다. 노드를 연결해 이미지·영상·음악·3D 결과물을 생성하는 작업 환경을 제공합니다. 입력, 생성, 가공, 출력을 담당하는 노드를 캔버스에 배치하고 서로 연결하면, 연결된 순서에 따라 순차적으로 작업이 실행됩니다.

주요 특징

통합 작업 환경이미지, 영상, 음악, 3D 모델, 3D 월드를 하나의 캔버스에서 연속으로 제작합니다.
단일 인터페이스, 다중 프로바이더모델 200종 이상을 제공하며, 프로바이더별 개별 가입이 필요하지 않습니다.
연결형 파이프라인생성, 색 보정, 합성, 영상화, 외부 프로그램 송출까지 하나의 흐름으로 구성합니다.
조직 단위 관리동일 캔버스의 실시간 공동 편집을 지원하며, 프로젝트와 크레딧을 조직 단위로 관리합니다.

제작 가능한 결과물

텍스트 기반 이미지 생성
프롬프트만으로 이미지를 생성하고, 생성한 이미지를 편집·합성·업스케일합니다.
이미지 기반 영상 생성
정지 이미지를 영상으로 변환하고, 음원을 연결해 입 모양을 동기화한 인물 영상을 제작합니다.
이미지 기반 3D·월드 생성
이미지 한 장에서 3D 모델을 추출하거나 파노라마 형태의 3D 월드를 생성합니다.
오디오 생성
프롬프트로 음악과 효과음을 생성하고, 영상 작업의 사운드로 연결합니다.
리얼타임 작업
웹캠 등 실시간 인풋 활용, 생성한 비주얼을 TouchDesigner·언리얼 등 외부 프로그램으로 실시간 송출합니다.
참고랜딩페이지의 "쇼케이스 보기"에서 실제 제작 사례를 확인할 수 있습니다.
01 시작하기/회원가입

회원가입

1.2 · Sign Up

이메일로 가입하고 인증 링크를 눌러 로그인합니다.

가입 전 확인 사항회사·팀 단위로 사용하는 경우 회사 도메인 이메일로 가입하는 것을 권장합니다. 조직에 합류하려면 조직 관리자(Admin)가 발급한 참여 코드가 필요합니다. 가입 전에 관리자에게 참여 코드를 요청하세요.

가입 순서

  1. 시작 화면 열기TabTo에 접속하면 로그인 화면이 표시됩니다. 신규 사용자는 하단의 "계정 만들기"를 누릅니다.
  2. 가입 정보 입력4개 항목(이메일 / 비밀번호 8자 이상 / 비밀번호 확인 / 이름)을 입력한 후 "계정 만들기"를 누릅니다.
  3. 이메일 인증메일함에서 TabTo가 발송한 메일을 열고 인증 링크를 클릭하면 인증이 완료됩니다.
  4. 로그인인증 완료 후 이메일과 비밀번호로 "로그인"합니다.

오류 메시지가 표시되는 경우

메시지조치
"비밀번호는 최소 8자 이상이어야 합니다."8자 이상으로 다시 입력합니다
"비밀번호가 일치하지 않습니다."확인 칸을 다시 입력합니다
이미 가입된 이메일 안내하단의 "로그인"으로 이동해 로그인합니다
핵심이메일 인증을 완료하기 전에는 로그인할 수 없습니다.
참고메일이 수신되지 않은 경우 스팸함을 확인하세요.
01 시작하기/승인 방법

승인 방법

1.3 · Approval

회원가입 절차를 완료하면 참여 코드 입력 화면이 표시됩니다. 이후 절차는 조직 내 역할에 따라 다릅니다.

조직 관리자 (Admin)

  1. 회원가입을 완료합니다
  2. 자이언트스텝 담당자에게 연락해 관리자 권한 부여를 요청합니다전달 정보: 가입 계정(이메일) / 이름 / 회사 소속
  3. 담당자가 관리자(Admin) 권한을 부여합니다
  4. 권한 부여가 완료될 때까지 대기합니다
참고구성원의 조직 합류는 참여 코드로 진행됩니다. 권한 부여 후 4.2 Organization에서 참여 코드를 확인해 구성원에게 전달하세요. 관리자 권한으로 수행하는 조직·구성원 관리는 4장 대시보드를 참고하세요.

조직 내 일반 사용자 (Member)

  1. 안내 화면에 코드를 입력합니다조직 관리자가 발급한 참여 코드로 진행합니다.
  2. "참여하고 로그인"을 누릅니다
  3. 즉시 승인되어 바로 사용할 수 있습니다
참고참여 코드 없이 로그인을 시도하면 "계정이 관리자 승인을 기다리고 있습니다."라는 안내가 표시됩니다. 이 경우 조직 관리자에게 참여 코드를 요청해 입력하세요.
01 시작하기/첫 화면까지

첫 화면까지

1.4 · Getting Started

작업 화면을 여는 순서는 다음과 같습니다.

다섯 단계

  1. 로그인합니다로그인을 완료하면 랜딩페이지가 아닌 워크스페이스의 내 파일(My Files) 화면으로 이동합니다.
  2. 작업공간(내 파일)에 도착합니다작업 파일이 모이는 기본 화면이며, 최초 접속 시에는 목록이 비어 있습니다.
  3. "새로 만들기"를 누릅니다왼쪽 메뉴, 화면 위쪽, 가운데 빈 영역의 버튼은 모두 동일하게 동작합니다.
  4. 이름을 입력합니다"워크플로우 생성" 창에 이름을 입력하고 "생성"을 누릅니다. 비워 두면 "새 워크플로우"라는 이름으로 생성됩니다.
  5. 빈 캔버스가 열립니다워크플로우 에디터에서 제작을 시작합니다.

02 워크플로우/노드 기반 작업 개념

노드 기반 작업 개념

2.2 · Node Concept

노드를 배치하고 연결하면 연결된 순서대로 작업이 실행됩니다.

노드의 4가지 역할

역할기능예시
Input데이터를 입력합니다텍스트, 이미지, 영상, 오디오, 웹캠, 드로잉
GenerationAI가 결과물을 생성합니다텍스트→이미지, 이미지→영상, 텍스트→오디오
Utility결과물을 보정·가공합니다색 보정, 자르기, 배경 제거, 합성
Output결과물을 확인·저장합니다이미지 출력, 영상 출력

노드 연결 방법

핸들에서 핸들로
노드 가장자리의 핸들에서 다른 노드의 핸들로 드래그하면 연결선이 생성됩니다.
데이터 타입이 일치할 때만
이미지 출력은 이미지 입력 핸들에, 텍스트 출력은 텍스트 입력 핸들에만 연결됩니다. 타입이 맞지 않는 핸들로 드래그하면 연결선이 생성되지 않습니다.
기존 연결의 교체
이미 연결선이 있는 입력 핸들에 새 연결을 시도하면 기존 연결이 교체됩니다.
실행 버튼의 위치실행 버튼은 Generation 노드가 아닌 Output 노드에 있습니다. 프롬프트·모델·옵션 설정은 Generation 노드에서 수행하고, 실행 버튼인 Generate는 뒤에 연결된 Output 노드에 있습니다. 따라서 Generation 노드 → Output 노드 순으로 연결해야 실행할 수 있습니다.

02 워크플로우/활용 가능 모델

05 에이전트 Wilson/Wilson이란?

Wilson이란?

5.0 · AI Agent

Wilson은 TabTo의 각 화면에 배치된 AI 에이전트입니다. 화면마다 하나씩 제공되며, 해당 화면의 업무 범위에 맞는 기능을 수행합니다. 동일한 에이전트이지만 위치에 따라 담당 역할이 다릅니다.

역할 4종

위치실행 버튼역할지원 범위
워크플로우 에디터AI 버튼Assistant대화로 워크플로우를 설계하고, 사용자가 승인하면 캔버스에 적용합니다
작업공간·즐겨찾기폴더 아이콘 버튼Workspace작업 파일을 검색·요약하고 열어 줍니다
에셋이미지 아이콘 버튼Asset Librarian결과물을 검색합니다
대시보드차트 아이콘 버튼Analytics사용량과 비용을 분석합니다 (관리 권한 전용)
참고버튼에 마우스를 올리면 "Wilson · …" 형식으로 역할 이름이 표시됩니다. 조직에 AI 키가 설정되지 않은 경우 버튼이 표시되지 않을 수 있습니다.

공통 원칙

사용자 확인 우선
Wilson이 직접 수행하는 범위는 역할마다 다릅니다. 공통 원칙은 사용자의 확인 없이 작업 내용을 변경하지 않는다는 것입니다. 각 절에서 직접 실행하는 범위와 제안에 그치는 범위를 구분해 표시합니다.

문제 해결

6.1 · Troubleshooting
노드가 연결되지 않습니다
데이터 타입이 일치하는 핸들인지 확인하세요. 이미지 출력은 이미지 입력 핸들에, 텍스트 출력은 텍스트 입력 핸들에만 연결됩니다. 이미 연결선이 있는 입력 핸들에 새 연결을 시도하면 기존 연결이 교체됩니다. 교체를 원하지 않으면 Switcher 노드로 입력을 전환하세요.
Generate 버튼이 동작하지 않습니다
Output 노드가 연결되어 있는지 확인하세요. 실행 버튼은 Output 노드에 있습니다. 필수 입력이 비어 있지 않은지 확인하세요. 립싱크 모델은 오디오 연결이 필수입니다. 에디터 상단에서 크레딧 잔액을 확인하세요.
결과물이 표시되지 않습니다
생성 결과는 자동으로 보관됩니다. Assets에서 조회하세요. 프로바이더가 제공하는 원본 링크는 만료될 수 있으나, TabTo가 사본을 별도로 저장합니다.
모델이 목록에 표시되지 않습니다
관리자가 비활성화한 모델은 목록에 표시되지 않습니다. 조직 관리자에게 문의하세요.

로그인이 되지 않습니다

메시지원인 및 조치
"로그인 전에 이메일을 인증해 주세요."메일함(스팸함 포함)에서 인증 링크를 클릭합니다
"계정이 관리자 승인을 기다리고 있습니다."조직 관리자에게 참여 코드를 요청해 입력합니다 (1.3 참고)
"이메일 또는 비밀번호가 올바르지 않습니다."다시 입력하고, 해결되지 않으면 "비밀번호를 잊으셨나요?"를 이용합니다

06 부록/외부 연동 가이드

외부 연동 가이드

6.5 · Blender · Unreal · Spout

Blender Bridge

  1. 애드온을 설치합니다Blender Bridge 노드에서 "Download Blender Addon"을 눌러 애드온을 내려받고 블렌더에 설치합니다.
  2. TabTo 탭을 엽니다블렌더 View3D 사이드바에서 TabTo 탭을 엽니다.
  3. 블렌더에서 보내고 TabTo에서 받습니다블렌더에서 "Render to TabTo" 또는 "Viewport to TabTo"를 실행한 후, TabTo 노드에서 Receive를 누릅니다.
  4. 3D 메시를 블렌더로 보냅니다TabTo에서 생성한 3D 메시는 "Send to 3D Mesh"로 블렌더에 전송할 수 있습니다.

Unreal Bridge

  1. 플러그인을 설치합니다노드에서 플러그인 버전을 선택한 후(예: Unreal Plugin 5.5) "Download"를 눌러 언리얼에 설치합니다.
  2. 언리얼에서 보내고 TabTo에서 받습니다언리얼에서 "Send Viewport"를 실행한 후, TabTo에서 "Receive Image" 또는 "Receive Sequence"를 누릅니다.
  3. 3D 메시 전송도 지원합니다

Spout (TouchDesigner 등 실시간 송출)

  1. Spout Output 노드를 연결합니다
  2. 데스크톱 컴패니언을 실행합니다"Launch Desktop Spout"로 실행합니다. 최초 1회 등록이 필요합니다.
  3. 외부 프로그램에서 수신합니다TouchDesigner·언리얼 등에서 Sender Name으로 수신합니다.
구성 예시Audio Analyzer → Audio Particle Reactive → Spout Output 구성으로, 오디오에 반응하는 비주얼을 공연 장비에 실시간 송출할 수 있습니다.
